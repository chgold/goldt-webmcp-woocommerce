WooCommerce tools for Goldnat — let AI agents read products, manage cart, and view orders on your store.

== Description ==

Add-on for the Goldnat WebMCP Bridge that exposes WooCommerce as AI-agent tools.

**Available tools:**
* searchProducts — Search products by keyword, filters
* getProduct — Fetch a single product
* addToCart — Add a product to the cart
* getCart — Read current cart contents
* getOrders — List customer orders

**Requires:** Goldnat WebMCP Bridge (free) + WooCommerce.

== Installation ==

1. Install and activate Goldnat WebMCP Bridge (free) from WordPress.org.
2. Install and activate WooCommerce.
3. Upload this plugin and activate it.
4. AI agents now see the WooCommerce tools in the manifest.
